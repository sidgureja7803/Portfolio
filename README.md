# Local Development

## Clone the repository

```bash
git clone https://github.com/sidgureja7803/Portfolio.git
```

## Install dependencies

```bash
cd Portfolio

npm install

# or

yarn install
```

## Run locally

```bash
npm start

# or

yarn start
```

Open:

```txt
http://localhost:3000
```

---

# Production Build

```bash
npm run build

# or

yarn build
```

The optimized production build will be generated inside:

```txt
build/
```
